Local Build Diagnostic Fallback
===============================

Purpose
-------

The normal project workflow is Docker-hosted and must be launched from the repository root through `scripts/dev.ps1` or `scripts/dev.sh`. This file is retained only as a diagnostic fallback reference for development-machine, CubeMX, IDE, or local toolchain investigation.

Normal secure-boot workflow
---------------------------

```powershell
.\scripts\dev.ps1 experiment build-wolfboot --algorithm <algorithm>
.\scripts\dev.ps1 experiment build --experiment configs/experiments/baseline_direct_uart.yaml --configure-preset RelocatedDebug --build-preset RelocatedDebug --artifact build/RelocatedDebug/stm32_basic_hal1.elf
.\scripts\dev.ps1 experiment sign-application --algorithm <algorithm>
.\scripts\dev.ps1 experiment-gateway flash-secure-boot --experiment configs/experiments/secure_boot_uart.yaml --algorithm <algorithm> --repeat-count 2
```

Signing-state safety
--------------------

Do not use destructive wolfBoot signing cleanup. Do not delete or replace the canonical private key, wolfBoot-local private key, generated public key, or generated `tools/wolfboot/src/keystore.c` as routine cleanup. These files form reusable local signing state.

The generated-state preflight is the supported compatibility and provenance mechanism. It may clean only configured generated outputs and stale final artifacts. It preserves canonical keys under `secrets/wolfboot/` and rejects incomplete or mismatched signing state before invoking the build.

Diagnostic fallback boundary
----------------------------

A host-native CMake, Make, Python, or IDE command may be used to isolate a local environment problem, but it is not the reproducible validation gate. After diagnosis, rerun the applicable Docker-wrapper command and verification tests. Native diagnosis must not bypass framework-generated state, recorded relocated-build provenance, signing records, or secure-boot artifact provenance.


Building Relocated application
------------------------------

.\scripts\dev.ps1 experiment build `
    --experiment configs/experiments/baseline_direct_uart.yaml `
    --results-dir results/secure-boot-matrix `
    --configure-preset RelocatedDebug `
    --build-preset RelocatedDebug `
    --artifact build/RelocatedDebug/stm32_basic_hal1.elf `
    --force

if ($LASTEXITCODE -ne 0) {
    throw "Relocated application build failed"
}

Run full matrix of secureboot profiles
--------------------------------------

$algorithms = @(
    "ecdsa_p256",
    "ecc384",
    "ecc521",
    "ed25519",
    "ed448",
    "rsa2048",
    "rsa3072",
    "rsa4096",
    "mldsa44",
    "mldsa65"
)

$resultsRoot = "results/secure-boot-matrix"

foreach ($algorithm in $algorithms) {
    Write-Host ""
    Write-Host "============================================================"
    Write-Host "Secure-boot end-to-end test: $algorithm"
    Write-Host "============================================================"

    Write-Host "[1/3] Building wolfBoot"
    .\scripts\dev.ps1 experiment build-wolfboot `
        --algorithm $algorithm `
        --results-dir $resultsRoot

    if ($LASTEXITCODE -ne 0) {
        throw "wolfBoot build failed for $algorithm"
    }

    Write-Host "[2/3] Signing relocated application"
    .\scripts\dev.ps1 experiment sign-application `
        --algorithm $algorithm `
        --results-dir $resultsRoot

    if ($LASTEXITCODE -ne 0) {
        throw "Application signing failed for $algorithm"
    }

    Write-Host "[3/3] Flashing and checking UART"
    .\scripts\dev.ps1 experiment-gateway flash-secure-boot `
        --experiment configs/experiments/secure_boot_uart.yaml `
        --algorithm $algorithm `
        --results-dir $resultsRoot `
        --uart-duration-seconds 15

    if ($LASTEXITCODE -ne 0) {
        throw "Secure-boot flash/UART test failed for $algorithm"
    }

    Write-Host "PASS: $algorithm"
}
