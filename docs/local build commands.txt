Local Build Diagnostic Fallback
===============================

Purpose
-------

The normal project workflow is Docker-hosted and must be launched from the repository root through `scripts/dev.sh`. This file is retained only as a diagnostic fallback reference for development-machine, CubeMX, IDE, or local toolchain investigation.

Normal secure-boot workflow
---------------------------

```bash
./scripts/dev.sh experiment build-wolfboot --algorithm <algorithm>
./scripts/dev.sh experiment build --experiment .pqc-generated-state/campaigns/baseline/cases/<case>.yaml --configure-preset RelocatedDebug --build-preset RelocatedDebug --artifact build/RelocatedDebug/stm32_basic_hal1.elf
./scripts/dev.sh experiment sign-application --algorithm <algorithm>
./scripts/dev.sh experiment-gateway flash-secure-boot --experiment .pqc-generated-state/campaigns/secure_boot/cases/<case>.yaml --algorithm <algorithm> --repeat-count 2
```

Signing-state safety
--------------------

Do not use destructive wolfBoot signing cleanup. Do not delete or replace the canonical private key, wolfBoot-local private key, generated public key, or generated `tools/wolfboot/src/keystore.c` as routine cleanup. These files form reusable local signing state.

The generated-state preflight is the supported compatibility and provenance mechanism. It may clean only configured generated outputs and stale final artifacts. It preserves canonical keys under `secrets/wolfboot/` and rejects incomplete or mismatched signing state before invoking the build.

Diagnostic fallback boundary
----------------------------

A host-native CMake, Make, Python, or IDE command may be used to isolate a local environment problem, but it is not the reproducible validation gate. After diagnosis, rerun the applicable Docker-wrapper command and verification tests. Native diagnosis must not bypass framework-generated state, recorded relocated-build provenance, signing records, or secure-boot artifact provenance.


Building Relocated application
------------------------------

```bash
./scripts/dev.sh experiment build \
    --experiment .pqc-generated-state/campaigns/baseline/cases/<case>.yaml \
    --results-dir results/secure-boot-matrix \
    --configure-preset RelocatedDebug \
    --build-preset RelocatedDebug \
    --artifact build/RelocatedDebug/stm32_basic_hal1.elf \
    --force

if [[ $? -ne 0 ]]; then
    echo "Relocated application build failed" >&2
    exit 1
fi
```

Run full matrix of secureboot profiles
--------------------------------------

```bash
algorithms=(
    "ecdsa_p256"
    "ecc384"
    "ecc521"
    "ed25519"
    "ed448"
    "rsa2048"
    "rsa3072"
    "rsa4096"
    "mldsa44"
    "mldsa65"
)

resultsRoot="results/secure-boot-matrix"

for algorithm in "${algorithms[@]}"; do
    echo ""
    echo "============================================================"
    echo "Secure-boot end-to-end test: ${algorithm}"
    echo "============================================================"

    echo "[1/3] Building wolfBoot"
    ./scripts/dev.sh experiment build-wolfboot \
        --algorithm ${algorithm} \
        --results-dir "$resultsRoot"

    if [[ $? -ne 0 ]]; then
        echo "wolfBoot build failed for ${algorithm}" >&2
        exit 1
    fi

    echo "[2/3] Signing relocated application"
    ./scripts/dev.sh experiment sign-application \
        --algorithm ${algorithm} \
        --results-dir "$resultsRoot"

    if [[ $? -ne 0 ]]; then
        echo "Application signing failed for ${algorithm}" >&2
        exit 1
    fi

    echo "[3/3] Flashing and checking UART"
    ./scripts/dev.sh experiment-gateway flash-secure-boot \
        --experiment .pqc-generated-state/campaigns/secure_boot/cases/<case>.yaml \
        --algorithm ${algorithm} \
        --results-dir "$resultsRoot" \
        --uart-duration-seconds 15

    if [[ $? -ne 0 ]]; then
        echo "Secure-boot flash/UART test failed for ${algorithm}" >&2
        exit 1
    fi

    echo "PASS: ${algorithm}"
done
```
